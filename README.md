# Sathish Kumar S — Portfolio Preview

A responsive, luxury editorial personal portfolio built with HTML, CSS and vanilla JavaScript.

## Brand direction
- Cream, black and champagne-gold palette
- Minimal SK monogram (SVG + PNG), browser favicon and social sharing card
- Playfair Display / DM Sans typography, responsive layout and reduced-motion support

## Included
- Hero, selected work, Richness Creator case study, About, Services, Creative Lab, Experience, Insights and Contact
- Project category filters and mobile navigation
- Email, phone, WhatsApp, Behance and GitHub links
- Contact form validation that prepares an email in the visitor's email app
- Basic SEO and Open Graph / social sharing metadata
- User-provided portrait assets

## Preview locally
Open `index.html` in a modern browser. For a more realistic preview, serve this folder using a local static server.

## Free preview deployment
1. Keep this ZIP as your backup and extract it.
2. Upload the project folder to a static hosting provider such as Netlify, Vercel, or GitHub Pages.
3. Use the provider's temporary preview URL first. Do not connect a paid domain yet.
4. Test desktop and mobile layouts, all links, the contact email handoff, favicon and social card.
5. Keep the site unannounced until the content and legal pages are approved.

## Must be completed before public launch
- Verify role dates, education, project details and every public claim against your CV / records.
- Replace any concept mockups with approved work samples where possible; label concept work clearly.
- Confirm you have permission to publish each screenshot or work sample; remove client, supplier and commercial confidential information.
- The contact form does **not** store submissions or send automated notifications; it opens the visitor's email app. A secure backend is needed for the planned admin dashboard, database, email confirmations and booking workflow.
- Privacy / Terms links are placeholders in this starter. Add reviewed full pages before collecting real enquiries.
- No admin login, booking calendar, PDF CV, analytics, database, email automation or custom domain is configured yet.
- Review cookie / analytics consent before adding analytics.

## Dark Cinematic Motion Edition
- Dark charcoal and champagne-gold visual theme.
- Hero portrait includes a slow cinematic sheen, subtle scanline, glow, floating SK stamp, and mouse-follow 3D tilt on desktop.
- Motion is reduced when the visitor enables reduced-motion accessibility settings; mobile remains touch-friendly.
- This is a CSS/JavaScript motion effect, not a video file or a true 3D model.
- Keep `index.html`, `styles.css`, `script.js`, and the `assets/` folder together in the repository root.
